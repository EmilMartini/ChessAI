# ChessAI

An unfinished chess project in C# and Blazor WebAssembly (.NET 5), started in March 2021.

What exists: an 8x8 board rendered in the browser, the starting position for both sides, and a class per piece type. What does not exist yet: making moves in the UI, and the AI the name promises.

Run it with `dotnet run` in the `ChessAI` folder and open `/chess`.
